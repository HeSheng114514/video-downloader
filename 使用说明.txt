================================================================
  视频下载器 v1.0.0  ——  使用说明
  支持：哔哩哔哩 / 抖音 / 快手 / TikTok / YouTube / 小红书 / 微博 等 1000+ 站点
================================================================

【一、两个版本怎么选】

  单文件版\VideoDownloader.exe
      · 只有一个 exe，方便拷贝传播
      · 双击即可运行，首次启动稍慢（需解压自身）

  便携版\VideoDownloader.exe
      · 一个文件夹（含 _internal 目录），启动更快
      · 若杀毒软件报"单文件版"可疑，请改用这个版本（更不容易误报）

  两个版本功能完全相同，任选其一使用。

【二、运行环境已内置，无需再下载】

  每个版本目录下已经准备好两套下载后端（互为备份）：

    bin\yt-dlp.exe     首选引擎（覆盖 1000+ 站点，可在线自我更新）
    bin\ffmpeg.exe     音视频合并 / 音频提取
    bin\ffprobe.exe    媒体信息探测
    vendor\            内置 yt-dlp 模块（备用通道）

  正常情况下程序使用 bin\yt-dlp.exe。如果它被杀毒软件拦截或
  无法运行，程序会自动切换到 vendor\ 里的内置模块继续工作，
  界面上仍显示 yt-dlp 可用，不会中断使用。

  因此首次运行不需要联网下载任何依赖，可直接开始下载视频。
  （如果删除了 bin 与 vendor 目录，程序会在首次运行时自动重新下载）

【三、使用方法】

  1. 双击 VideoDownloader.exe
  2. 把视频链接或分享文案粘贴到链接框（每行一个，支持直接粘贴
     "7.85 复制打开抖音，看看……" 这类整段文字，程序会自动提取链接）
  3. 点「🔍 解析」或按 Ctrl+Enter
  4. 右上角选择画质（最佳 / 4K / 2K / 1080P / 720P / 480P / 仅音频 MP3）
  5. 点「⬇ 开始下载」
  6. 表格中可看进度、速度、剩余时间；右键可打开文件、重试、取消
     双击已完成的任务可直接播放

【四、抖音 / 快手 需要登录 Cookie（重要）】

  这两个平台启用了风控，匿名请求会被拦截。解决方法：

    方法 A（推荐）：用 Chrome 或 Edge 登录抖音/快手，
            打开程序 → 🛠 设置 → 网络与登录 →
            「从浏览器读取 Cookie」选择 chrome 或 edge → 保存
            注意：Chrome 占用 Cookie 时可能读取失败，可先完全退出浏览器

    方法 B：浏览器安装扩展 "Get cookies.txt LOCALLY"，
            在目标网站导出 cookies.txt，然后在设置中选择该文件

  哔哩哔哩 1080P 以上、YouTube 会员内容 同样建议配置 Cookie。

【五、YouTube / TikTok 需要代理】

  设置 → 网络与登录 → 代理服务器，填写例如：
      http://127.0.0.1:7890
      socks5://127.0.0.1:1080

【六、常见问题】

  · 提示"未找到 yt-dlp"
      → 打开标题栏「⚙ 运行环境」→ 一键安装 / 修复
  · 提示需要 Cookie / 验证码
      → 见第四节
  · 下载后没有声音
      → 确认 bin\ffmpeg.exe 存在；打开「⚙ 运行环境」检查
  · 杀毒软件报毒
      → PyInstaller 打包程序的常见误报，改用「便携版」，或把程序
        目录加入杀软白名单
  · 下载中断
      → 支持断点续传，右键任务「重新下载」即可续传
  · 想装到别的电脑
      → 整个文件夹拷过去即可（绿色免安装）

【七、源码与重新打包】

  程序源码在主目录（上一级），可修改后重新打包：
      powershell -ExecutionPolicy Bypass -File 构建EXE.ps1
  产物输出到 dist\ 目录。
